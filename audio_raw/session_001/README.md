# 🎧 audio_raw

This folder contains raw audio recordings from BLACKBOX voice interface tests.

These recordings are used to:
- Compare user speech to ChatGPT (or other AI) responses
- Detect mismatches, glitches, and fallback phrase insertions
- Audit potential compliance-based moderation behaviors

## 🔐 Privacy & Ethics

- All recordings are self-generated by the user/tester.
- No third-party audio is permitted without consent.
- These files are **not** committed to GitHub by default (see `.gitignore`).
- Use for **glitch analysis only**, not for public broadcast or training.

## 🧪 Naming Convention

session_<ID>_<topic>.wav

Example:
- `session_001_zuo_de_hao.wav`
- `session_002_chinese_pronunciation_test.wav`

## 🧰 File Types

- `.wav` (preferred, lossless)
- `.mp3` (optional for previews)
- `.json` (optional matching transcript)
