# BLACKBOX: AI Voice Compliance Tracker

> “The voice you hear is not always the voice that was spoken.”

**BLACKBOX** is a user-led, open-source system designed to detect, log, and analyze audio input failures, compliance artifacts, and system-generated fallbacks in AI voice interfaces (starting with ChatGPT).

## 🎯 Purpose

- Track "glitch phrases" like "Visit chat.google.com" or "Transcript unavailable"
- Identify mismatches between spoken input and system response
- Build a searchable glitch database for transparency
- Map compliance patterns over time and updates

## 🔧 Features

- Local voice recording + offline transcription
- Detection of filler PR language or suppressed inputs
- Session logging and tagging
- Streamlit UI for reviewing and exporting sessions
- Open compliance glossary in development
